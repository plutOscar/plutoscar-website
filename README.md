# PLUTOSCAR — Multi-page website preview

This project is a responsive, multi-page personal brand website. Unlike the earlier single-page draft, each navigation link opens its own page.

## Pages

- `index.html` — Home
- `services.html` — Services and current skill areas
- `portfolio.html` — Real project screenshots, project descriptions, search and category filters
- `about.html` — About PLUTOSCAR and development focus
- `certificates.html` — Three STEMpedia certificates, original PDFs and image previews
- `contact.html` — Contact details and enquiry form

## Run it locally

1. Extract the ZIP file.
2. Open the extracted `PLUTOSCAR-MultiPage-Preview` folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open it directly in Chrome.
4. Use the navigation to visit the other pages. Keep the folder structure intact so assets and CSS/JS load correctly.

## Main folders

- `css/General.css` — colour variables, typography, cards, page layouts and responsive rules.
- `css/Header.css` — sticky header, navigation, mobile menu and site search.
- `js/main.js` — mobile navigation, portfolio filtering/search, image lightbox, form validation and back-to-top.
- `assets/photos/` — your supplied photographs.
- `assets/projects/` — your supplied PictoBlox screenshots.
- `assets/certificates/` — three original STEMpedia PDF certificates and rendered previews.
- `learning-reference/` — your original uploaded HTML/CSS files preserved for comparison.
